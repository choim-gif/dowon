# 우선순위 실행리스트 — 클라우드 동기화 설정 안내

체크 기록을 **구글 시트 한 곳에 저장**해서, 어느 브라우저·어느 컴퓨터에서 열어도
같은 기록이 유지되도록 하는 설정입니다.

---

## ✅ 이 설정은 이미 완료되었습니다 (2026-07-11)

- **저장소 시트:** 「우선순위-체크-저장소」 (내 구글 드라이브)
- **웹앱 URL:** priority.html의 `SYNC_URL`에 이미 입력됨
- **동작 확인:** 저장(POST)·불러오기(GET) 왕복 테스트 통과, 저장소 초기화 완료

이제 index 페이지에서 우선순위 실행리스트를 열고 체크하면 자동으로 구글 시트에 저장되고,
다른 브라우저·컴퓨터에서 열면 최신 기록을 자동으로 불러옵니다.

> 아래 내용은 나중에 URL을 다시 발급받거나 재설정할 때를 위한 참고용입니다.

---

## 1단계 · 구글 시트 만들기

1. [sheets.new](https://sheets.new) 로 새 구글 시트를 하나 만듭니다.
   (기존 OKR 시트를 써도 되지만, **기록 전용으로 새 시트를 만드는 걸 추천**합니다.)
2. 시트 이름은 아무거나 좋습니다. 예: `우선순위-체크-저장소`

## 2단계 · Apps Script 열기

1. 그 시트 상단 메뉴에서 **확장 프로그램 → Apps Script** 를 클릭합니다.
2. 새 탭에 코드 편집기가 열립니다. 기본으로 있던 `function myFunction() {}` 내용을 **전부 지웁니다.**
3. 이 폴더의 **`apps-script-code.gs`** 파일 내용을 **전부 복사해서 붙여넣기** 합니다.
4. 상단의 💾 (저장) 아이콘을 눌러 저장합니다.

## 3단계 · 웹앱으로 배포

1. 편집기 오른쪽 위 **배포 → 새 배포** 를 클릭합니다.
2. 왼쪽 톱니바퀴(유형 선택) → **웹 앱** 을 선택합니다.
3. 설정을 이렇게 맞춥니다:
   - **실행 계정(Execute as):** 나(본인)
   - **액세스 권한(Who has access):** **모든 사용자(Anyone)**
     → 로그인 없이 접근되도록 하는 설정입니다. (반드시 "모든 사용자")
4. **배포** 를 누릅니다.
5. 처음이면 **권한 승인** 창이 뜹니다.
   → 본인 구글 계정 선택 → "고급" → "(안전하지 않음)... 이동" → **허용**.
   (본인이 만든 스크립트라 안전합니다.)
6. 배포가 끝나면 **웹 앱 URL** 이 나옵니다. 예:
   `https://script.google.com/macros/s/AKfy...../exec`
   → 이 URL을 **복사** 합니다.

## 4단계 · priority.html에 URL 붙여넣기

1. 이 폴더의 **`priority.html`** 파일을 메모장(또는 편집기)으로 엽니다.
2. 파일 위쪽에서 이 줄을 찾습니다:

   ```
   const SYNC_URL   = "";
   ```

3. 따옴표 안에 방금 복사한 웹앱 URL을 붙여넣습니다:

   ```
   const SYNC_URL   = "https://script.google.com/macros/s/AKfy...../exec";
   ```

4. 저장합니다. (바로 아래 `SYNC_TOKEN` 값은 건드리지 마세요 — 스크립트 코드의 값과 이미 일치합니다.)

## 완료 ✅

이제 index 페이지를 열고 우선순위 실행리스트에서 체크를 해보세요.
- 체크할 때마다 자동으로 구글 시트에 저장됩니다.
- 다른 브라우저나 다른 컴퓨터에서 열면, 열 때 자동으로 최신 기록을 불러옵니다.
- (구글 시트의 `store` 탭 A2 칸에 기록이 JSON으로 쌓입니다. 지우지 마세요.)

## 자주 묻는 질문

**Q. `SYNC_URL`을 비워두면?**
예전처럼 그 브라우저에만 저장됩니다(오프라인 모드). 설정 전에도 페이지는 정상 동작합니다.

**Q. 기록이 안 불러와져요.**
- 3단계에서 액세스 권한이 **"모든 사용자"** 인지 확인하세요. (가장 흔한 원인)
- 코드를 수정한 뒤에는 **배포 → 배포 관리 → 편집(연필) → 버전: 새 버전 → 배포** 로 재배포해야 반영됩니다.
- `apps-script-code.gs`의 `TOKEN` 과 `priority.html`의 `SYNC_TOKEN` 값이 같은지 확인하세요.

**Q. 보안이 걱정돼요.**
URL을 아는 사람만 접근할 수 있고, `SYNC_TOKEN`이 맞아야 저장/조회됩니다.
URL은 본인 컴퓨터의 로컬 파일에만 들어있으니 외부에 공유하지 않는 한 안전합니다.
더 강화하려면 `apps-script-code.gs`와 `priority.html`의 토큰 값을 둘 다 같은 새 문자열로 바꾸면 됩니다.
