# 노션 데이터베이스 설계

블로그 글은 전부 노션에서 씁니다. 아래 속성 이름은 코드가 그대로 참조하므로 **글자 하나도 다르면 안 됩니다.**

## 속성 목록

| 속성 이름 | 유형 | 필수 | 설명 |
|---|---|---|---|
| `제목` | 제목(Title) | 필수 | 페이지의 h1이자 `<title>`이 됩니다. 32자 이내로 씁니다. |
| `슬러그` | 텍스트 | 선택 | URL에 쓰입니다. 비우면 제목에서 자동 생성됩니다. |
| `요약` | 텍스트 | 권장 | 검색결과 설명문이 됩니다. 비우면 첫 문단이 쓰입니다. 80~120자로 씁니다. |
| `카테고리` | 선택(Select) | 권장 | 목록 분류와 관련 글 추천에 쓰입니다. |
| `태그` | 다중 선택 | 선택 | 구조화 데이터의 keywords로 들어갑니다. |
| `상태` | 선택(Select) | 필수 | `초안` / `검수` / `발행` 중 하나입니다. `발행`만 사이트에 나갑니다. |
| `노출` | 체크박스 | 필수 | 체크된 글만 빌드에 포함됩니다. 급히 내릴 때 체크만 해제하면 됩니다. |
| `발행일` | 날짜 | 필수 | 정렬 기준이자 `datePublished`입니다. |
| `최종수정일` | 날짜 | 권장 | `dateModified`입니다. 제도가 바뀌어 글을 고칠 때 갱신합니다. |
| `작성자` | 텍스트 | 권장 | 공인노무사 실명입니다. E-E-A-T에 직접 영향을 줍니다. |
| `작성자직함` | 텍스트 | 선택 | 비우면 `공인노무사`가 기본으로 들어갑니다. |
| `근거법령` | 텍스트 | 권장 | 예: 고용보험 및 산업재해보상보험의 보험료징수 등에 관한 법률 제15조 |
| `근거법령링크` | URL | 선택 | 법령정보센터 등 정부 사이트 주소를 넣습니다. |
| `대표이미지` | 파일과 미디어 | 선택 | 공유 카드 이미지입니다. 외부 URL 사용을 권장합니다. |
| `CTA유형` | 선택(Select) | 선택 | `무료진단` / `체크리스트` / `상담` / `없음`. 비우면 `무료진단`입니다. |

### 선택 속성의 옵션값

- `상태` : 초안, 검수, 발행
- `CTA유형` : 무료진단, 체크리스트, 상담, 없음
- `카테고리` : 사내근로복지기금, 지원금·환급금, 고용산재 확정정산, 산업재해, 4대보험, 건설 노무, 인사노무 일반 (필요에 따라 추가)

> `대표이미지`에 노션에 직접 업로드한 파일을 쓰면 URL이 1시간 뒤 만료됩니다. 빌드 시점에는 유효하므로 정적 HTML에는 박히지만, 장기적으로는 외부 URL(홈페이지에 올린 이미지 주소)을 쓰는 편이 안전합니다.

## 본문 작성 규칙

### 제목 단계는 한 칸씩 내려갑니다

페이지 제목이 이미 h1이므로 본문에는 h1을 만들지 않습니다. 노션에서 쓰는 제목 블록은 다음과 같이 변환됩니다.

| 노션에서 쓰는 것 | 실제 HTML | 용도 |
|---|---|---|
| 제목1 | `<h2>` | 글의 주요 섹션입니다. **3개 이상 필요합니다.** |
| 제목2 | `<h3>` | 섹션 안의 세부 항목입니다. |
| 제목3 | `<h4>` | 더 잘게 나눌 때만 씁니다. |

제목1은 질문형으로 쓰면 좋습니다. `적용 대상`보다 `누가 적용 대상인가`가 검색과 AI 인용 양쪽에 유리합니다.

### 첫 문단이 검색결과에 그대로 나갑니다

`요약`을 비워두면 첫 문단이 검색결과 설명문이 됩니다. 그래서 첫 문장은 인사말이 아니라 결론이어야 합니다.

```
쓰지 않습니다  안녕하세요, 노무법인 도원입니다. 오늘은 산재보험료에 대해 알아보겠습니다.
이렇게 씁니다  산재를 신청해도 대부분의 중소 사업장은 보험료가 오르지 않습니다.
              개별실적요율은 상시근로자 30인 이상 사업장에만 적용되기 때문입니다.
```

### FAQ는 토글로 만듭니다

`자주 묻는 질문`이라는 제목1을 만들고 그 아래에 **토글 블록**을 넣으면, 토글 제목이 질문, 토글 내용이 답변으로 인식되어 FAQ 구조화 데이터가 자동 생성됩니다. 구글 검색결과에 질문 목록이 펼쳐질 수 있고 AI 검색 인용률도 올라갑니다.

```
제목1 : 자주 묻는 질문
  토글 : 산재 처리하면 보험료가 얼마나 오르나요?
      → 30인 미만 사업장은 개별실적요율 적용 대상이 아니라 오르지 않습니다.
  토글 : 공상처리하면 신고하지 않아도 되나요?
      → 아닙니다. 산업재해조사표는 별도로 제출해야 합니다.
```

### 표를 적극적으로 씁니다

수치 비교나 조건 정리는 문장보다 표가 낫습니다. AI 검색이 표를 인용하는 비율이 높습니다.

### 지원되는 블록

문단, 제목1~3, 글머리 기호 목록, 번호 목록, 표, 이미지, 인용, 콜아웃, 토글, 구분선, 코드, 북마크, 유튜브 영상, 다단 레이아웃을 지원합니다. 그 외 블록은 조용히 무시되므로 화면에 나오지 않습니다.

## 통합(Integration) 연결

1. [notion.so/my-integrations](https://www.notion.so/my-integrations)에서 새 내부 통합을 만들고 이름을 `도원 블로그`로 지정합니다.
2. 발급된 시크릿을 `NOTION_TOKEN`으로 씁니다.
3. 만든 데이터베이스 페이지 우측 상단 `···` → `연결` → 방금 만든 통합을 추가합니다. **이 단계를 빠뜨리면 권한 오류가 납니다.**
4. 데이터베이스 URL에서 32자리 ID를 복사해 `NOTION_DATABASE_ID`로 씁니다.

```
https://www.notion.so/워크스페이스/1a2b3c4d5e6f7890abcdef1234567890?v=...
                                  └────────── 이 부분 ──────────┘
```
